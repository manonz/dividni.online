Online Applications

Dividni provides a suite of online applications that simplify the creation, administration, and marking of multiple-choice examinations.

Paper-based Assessment Applications

OMR Processor
Processes scanned OMR answer sheets and automatically extracts each student's responses. This is the first step in the marking workflow.
MCQ Grader
Marks processed responses using the answer keys generated by Dividni and produces grades and reports. This is the second step in the marking workflow.
OMR Editor
Allows you to customise Dividni OMR answer sheets. You can edit selected text (for example, for internationalisation), replace or remove institutional logos, and make other supported customisations.
Scanera
An exam identity verification tool that allows invigilators to capture a student's photograph during an examination and verify their identity against an uploaded class list.

Online Assessment Applications

QBanks
A question bank generation tool that transforms reusable question generators into comprehensive banks of assessment items. QBanks supports export to widely used Learning Management Systems (LMS), such as Moodle, Canvas, and Sakai, as well as digital assessment platforms such as Inspera.

Typical paper-based assessment workflow: (Optional) Customise the OMR answer sheet using OMR Editor. Generate exam papers using Dividni (with either the customised or default OMR sheet included). Scan completed answer sheets using OMR Processor. Mark responses using MCQ Grader. (Optional) Use Scanera during the examination to verify student identities.

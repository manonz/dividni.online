Dividni Online Applications

Dividni provides a suite of online applications that simplify the creation, administration, and marking of multiple-choice examinations. Dividni supports robust paper-based assessment workflows, which remain an effective approach for secure examinations, as well as online assessment workflows for contexts where digital delivery is required.

Secure Paper-based Assessment Applications

OMR Processor

Processes scanned OMR answer sheets and automatically extracts each student's responses. This is the first step in the marking workflow.

MCQ Grader

Marks processed responses using Dividni-generated answer keys and produces grades and reports. This is the second step in the marking workflow.

OMR Editor

Allows customisation of Dividni OMR answer sheets. You can edit selected text (for example, for internationalisation), replace or remove institutional logos, and make other supported customisations.

Scanera

An exam identity verification tool that uses a laptop or mobile device camera together with barcode scanning of student ID cards to assist invigilators in verifying student identities. The captured information is checked against an uploaded class list.

Online Assessment Applications

QBanks

A question bank generation tool that transforms reusable question generators into comprehensive banks of assessment items. QBanks supports export to Learning Management Systems (LMS) such as Moodle, Canvas, and Sakai, as well as digital assessment platforms such as Inspera.

Typical paper-based assessment workflow:

(Optional) Customise OMR answer sheets using OMR Editor. Generate examination papers using Dividni, including the customised or default OMR answer sheet. Scan completed answer sheets using OMR Processor. Mark responses using MCQ Grader. (Optional) Use Scanera during the examination to assist with student identity verification.
